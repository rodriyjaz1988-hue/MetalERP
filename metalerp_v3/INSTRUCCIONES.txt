PRIMERA INSTALACION:
  1. Descomprimir el ZIP
  2. Asegurarse de tener Python 3.10+ y Flask instalados
  3. Ejecutar INICIAR_SERVIDOR.bat
  4. Abrir http://localhost:5000/app

ACTUALIZAR INSTALACION EXISTENTE:
  1. Descomprimir el ZIP en cualquier carpeta
  2. Ejecutar ACTUALIZAR.bat
  3. Ingresar la ruta de tu instalacion (ej: C:\MetalERP\metalerp_v3)
  4. Reiniciar INICIAR_SERVIDOR.bat
  5. La base de datos NO se modifica - las migraciones se aplican automaticamente

ACCESO:
  - Version React:    http://localhost:5000/app
  - Version legacy:   http://localhost:5000

DESARROLLO (opcional):
  Si queres modificar el frontend React:
  1. Instalar Node.js 20+
  2. cd metalerp_react
  3. npm install
  4. npm run dev      (hot reload en localhost:5173)
  5. npm run build    (compila a metalerp_v3/static/dist)
