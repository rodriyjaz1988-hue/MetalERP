Qué hay que hacer en la máquina

    

      
Fanuc (tornos y centros con control Fanuc): cable de red al control, IP cargada en SYSTEM → EMBED PORT → COMMON, y en FOCAS2 el puerto TCP 8193. Se lee la variable #3901 (PARTS COUNT de la pantalla SETTING); si no, el parámetro 6711.

      
Haas: cable de red, IP en Settings → Network y el Setting 143 (Machine Data Collect) activado. Se lee el contador M30 #1 por el puerto 5051.

      
Con Probar se lee una vez el contador sin cargar piezas: sirve para saber si la conexión anda.
